I The terms

{% comment %} Each terms field wears two hats: class="autosave" inside a data-field container feeds the shared autosave (the draft saves on blur, so the round trip to the character editor loses nothing), and form="setup-start-form" submits the same values with the Begin press, where the server merges them before compiling. {% endcomment %} {% comment %} Required, and said so (issues #702 and #714). "Begin the battle" refused without a name while the field carried no asterisk, no hint and no error mark, so the reader learned the rule only from a banner at the top of a page whose empty box was 1,200px below it. The `required` attribute is the first line: the form attribute puts this input in setup-start-form, so the browser refuses the press and focuses the box without a round trip at all. The server still checks (start_draft), and when it refuses, the sentence is rendered here rather than only at the top (issue #711). {% endcomment %} {% comment %} Who decides, chosen before the fight rather than inferred from it (#308). This is the battle's *default*: every combatant inherits it, and any one of them can be given its own mode from the battle page once the fight is on. Claiming a seat still means "I play this one", whatever the default says. {% endcomment %} {% if is_dm %} {% comment %} Whether this battle counts (issues #750, #751; coordinator's ruling, Spencer may overrule): a Game Master's battle writes each wound, Mana spent and death to the saved characters' records unless this is turned off. A player's battle never does, so a player is not offered the choice at all. Saved like every other term, and the battle page says so whenever it is on. {% endcomment %} {% endif %}
