# Dungeons & Ruins

Generate an old site: who built it, what it was for, what lives there now, and what is worth carrying out.

Prefer not to roll by hand? The [Ruin Generator](/tarmar/gm/ruins/) rolls every table below and shows each die alongside the result.

## Ruin Origin

| d8  | Built by...                               |
| --- | ----------------------------------------- |
| 1   | The Lantern Kings or their servants       |
| 2   | A people who lived here before the present ones |
| 3   | Builders who were not human               |
| 4   | A lord whose line has died out            |
| 5   | A school of wizards or a hidden cult      |
| 6   | A garrison of a forgotten war             |
| 7   | No one can say                            |
| 8   | Several builders, each over the last      |

| d6  | Original Purpose                              |
| --- | --------------------------------------------- |
| 1   | Tomb or memorial                              |
| 2   | Temple or shrine                              |
| 3   | Fortress or watchtower                        |
| 4   | Hall, palace or manor                         |
| 5   | Working site (mine, forge, granary, cistern)  |
| 6   | Place of learning (library, observatory, laboratory) |

| d8  | Current State                                  |
| --- | ---------------------------------------------- |
| 1   | Sealed, never opened or closed again           |
| 2   | Partly explored, with the explorers' marks     |
| 3   | Occupied                                       |
| 4   | Stripped of anything easy to carry             |
| 5   | Unsafe: flooding, subsiding or falling in      |
| 6   | Still working: something in it runs            |
| 7   | Contested by more than one party               |
| 8   | Warded or cursed                               |
