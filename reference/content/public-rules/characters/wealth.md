# Wealth

Roll percentile dice. The table used to let a player choose instead ("or
choose if you don't want to be rich"); the ruling of 2026-09-28 overrides that
choice: a player rolls wealth once and cannot choose it. The starting coin is
rolled with it, once, and choosing a level again never rolls it again; only
the GM sets wealth or coin, or rolls them again. Rich gives no coin figure:
the GM sets it.

| Percentile | Level       | Starting Coin         |
| ---------- | ----------- | --------------------- |
| 0-15       | Subsistence | 10                    |
| 16-70      | Moderate    | 100                   |
| 71-95      | Merchant    | 100 + percentile dice |
| 96-100     | Rich        | Consult GM            |
