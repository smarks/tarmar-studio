# Location

Roll percentile dice or choose:

| Percentile | Location   |
| ---------- | ---------- |
| 01-20      | City       |
| 21-70      | Village    |
| 71-99      | Rural      |
| 100        | Consult GM |

A **Consult GM** result is the GM's to decide: where the character is from,
what that gives them, and whether they can read. The sheet records the GM's
ruling and says it is one.

## Location Effects

**City:** Street smarts; Literacy on INT check

**Village:** Street smarts OR survival (choose); Literacy on INT check +2

**Rural:** Survival (hunting, tracking, wood/herb lore); Literacy on INT check +4

The literacy modifier is a penalty — letters are harder to come by the further you live from a city. Add it to the 3d6 literacy roll, or equivalently subtract it from INT. City literacy is 3d6 ≤ INT; Village literacy is 3d6 ≤ INT − 2; Rural literacy is 3d6 ≤ INT − 4.

This is the check to be literate at all, and is separate from the [Literacy skill](../prior-experience/skills-glossary).
