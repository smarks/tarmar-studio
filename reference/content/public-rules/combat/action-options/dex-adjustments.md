# Situational Modifiers

These are the old DEX adjustments, re-signed for the **d20 roll-over** system.
Each one now changes either the **attacker's to-hit total** (positive = easier)
or the **defender's Target Number** (see [[attack-rolls]]). All are cumulative.

## Positional Advantage (add to attacker's to-hit roll)

| Situation | To-hit |
| --------- | ------ |
| Striking from enemy's side hex | +2 |
| Striking from enemy's rear hex | +4 |
| Pole-weapon vs. charging opponent | +2 |
| Crossbow fired from prone | +1 |
| Waiting for an opening (1 turn) | +1 |
| Waiting for an opening (2+ turns) | +2 |
| HTH combat | +4 (both) |

## Target Conditions (subtract from attacker's to-hit roll)

| Condition | To-hit |
| --------- | ------ |
| Target is invisible | −6 |
| Target is in a shadow hex | −4 |
| Target is a one-hex figure in flight | −4 |
| Target is a giant snake | −3 |
| Target is a multi-hex figure in flight | −1 |

## Your Conditions (subtract from attacker's to-hit roll)

| Condition | To-hit |
| --------- | ------ |
| In shadow hex or firing through shadow | −6 |
| Two-weapon fighting | −4 on both |
| Sweeping blow (all 3 front hexes) | −4 |
| Standing in fire | −2 |
| Standing on a body | −2 |
| Moving over broken ground | −2 |

## Range (Thrown Weapons)

−1 to hit per hex to target.

## Range (Missile Weapons)

| Range (Megahexes) | To-hit |
| ----------------- | ------ |
| 0–2 MH | 0 |
| 3–4 MH | −1 |
| 5–6 MH | −2 |
| 7–8 MH | −3 |
| (continues) | −1 per 2 MH |

## Armour and Shields

Armour is no longer a flat to-hit adjustment — it is handled by the **weapon-class
× armour-tier matrix** that sets the base Target Number (see [[attack-rolls]]).
**Shields** add to the defender's Target Number instead:

| Shield | TN |
| ------ | -- |
| Small / spike shield | +1 |
| Large shield | +2 |
| Tower shield | +3 |
| Main-gauche (parry) | +1 |
